# AI 사용 기록

## 주요 요청

- 사용자: 화면길잡이 프로젝트의 중간보고서와 설계 자료를 읽고, 사진 인식 앱 2107번 미니프로젝트 1단계를 Codex로 제작할 수 있는지 확인하고 제작.
- 구현 요청의 핵심: 카메라 또는 갤러리에서 이미지 한 장을 가져와 화면에 표시하고, 권한 요청·거부·재시도 흐름을 처리.

## 적용 및 수정

1. 기존 Flutter→Kotlin OCR 시험 앱의 자동 분석 화면을 1단계 이미지 입력 화면으로 교체. 이전 분석 화면 코드는 `lib/legacy_analysis.dart`에 보존.
2. 카메라·갤러리 입력, 미리보기, 이미지 표시, 권한 거부 안내, 시스템 설정 이동, 취소·파일 오류 처리를 추가.
3. Android 카메라 권한 선언과 README 실행·권한 처리 설명을 추가.

## 검증 기록

- Dart 정적 분석: `No issues found!`.
- Flutter 위젯 테스트: `All tests passed!`.
- Android 디버그 APK 빌드: 통과.
- 카메라·갤러리·권한 흐름의 실제 기기 검증은 아직 하지 않았습니다. 실제 기기 화면 캡처는 만들어 낸 이미지로 대체하지 않습니다.
