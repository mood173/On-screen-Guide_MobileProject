# AI 프롬프트와 반영 기록 · MP3

- 사용자 요청: MP2와 같은 앱에 분석 텍스트 이력 저장·목록·삭제·재시작 유지, 시스템 공유 시트, 원본 이미지 비저장, `PRIVACY.md`.
- Codex 제안·채택: Android `SharedPreferences`에 UUID·저장 시각·결과 텍스트만 동기 저장하고 MethodChannel로 Flutter 목록/삭제 화면을 연결. 공유는 `ACTION_SEND`의 `text/plain`을 사용.
- 실제 검증 후 수정: 긴 인식 텍스트가 이력의 공유·삭제 버튼을 밀어내는 문제를 확인해 목록 미리보기를 6줄로 제한. 이전 버전의 사진 선택기 캐시가 남은 것을 확인해 앱 시작 시 앱 소유 이미지 캐시를 정리하고, 분석 완료 시 현재 임시 복사본을 삭제하도록 함.
- 에뮬레이터에서 분석→재시작 후 이력→시스템 공유 시트→삭제 후 빈 목록을 직접 확인. 원본 비저장 범위와 강제 종료 시 임시 캐시 가능성은 `PRIVACY.md`에 명시.
