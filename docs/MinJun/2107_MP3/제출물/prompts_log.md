# AI 사용 기록 · MP3

사용한 도구: Codex(코딩 에이전트). 아래 요청은 실제로 보낸 내용을 요지로 줄여 적었습니다.

## 1. 주요 프롬프트

| 번호 | 요청 요지 | AI의 답 요지 |
|---|---|---|
| 1 | MP2와 같은 앱에 분석 결과 이력을 저장하고, 목록과 삭제를 만들고, 재시작해도 남게 해 달라. | Android `SharedPreferences`에 UUID·저장 시각·결과 글자만 저장하고, MethodChannel로 Flutter 목록·삭제 화면과 잇겠다. |
| 2 | 결과를 시스템 공유 시트로 다른 앱에 보낼 수 있게 해 달라. | `ACTION_SEND`, `text/plain`으로 글자만 넘기겠다. |
| 3 | 원본 이미지는 저장하지 않게 하고, 무엇을 저장하고 저장하지 않는지 `PRIVACY.md`로 정리해 달라. | 이력에는 글자만 넣고 저장·비저장 항목을 문서로 정리. |

## 2. 채택한 것

- 이력 항목은 `id`, `createdAt`, `text` 세 개뿐. 이미지 경로조차 넣지 않는다.
- 저장은 `commit()`으로 바로 디스크에 쓴다. 강제 종료 뒤에도 남아야 한다.
- 공유는 별도 패키지 없이 Android 기본 공유 시트.
- `allowBackup="false"`. 이력이 기기 백업으로 빠져나가지 않게 한다.

## 3. 실행해 보고 고친 것

| 실행해서 발견한 문제 | 고친 내용 |
|---|---|
| 인식한 글자가 길면 이력 카드에서 공유·삭제 버튼이 화면 밖으로 밀림 | 목록에서는 앞부분 6줄만 보여 주게 제한 |
| 이전 버전에서 사진 선택기가 만든 이미지 복사본이 앱 캐시에 남아 있었음 | 앱을 시작할 때 캐시의 이미지 파일을 정리(`purgeCachedImages`) |
| 분석이 끝난 뒤에도 방금 쓴 임시 복사본이 남음 | 분석 완료 시와 화면을 떠날 때 삭제(`releaseImage`). 앱 캐시 폴더 안의 파일만 지우도록 경로를 검사 |
| "원본을 저장하지 않는다"고만 쓴 초안 | 강제 종료하면 다음 시작 전까지 임시 복사본이 남을 수 있다는 한계를 `PRIVACY.md`에 적음 |

## 4. 검증

- 에뮬레이터에서 분석 → 강제 종료·재시작 후 이력 유지 → 공유 시트 → 삭제 후 빈 목록을 직접 확인하고 `screenshots/`에 넣었다.
- `adb shell run-as`로 앱 `cache/`에 이미지 파일이 남지 않은 것을 확인했다.
- `dart analyze`, `flutter test`, 디버그 APK 빌드 통과.
