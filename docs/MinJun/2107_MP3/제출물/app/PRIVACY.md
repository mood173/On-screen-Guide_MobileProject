# 개인정보 및 이미지 보관 범위

## 기기에 저장하는 항목

- 분석으로 얻은 **결과 텍스트**. 글자가 없으면 “글자를 찾지 못했어요”라는 안내 텍스트를 저장합니다.
- 이력 식별용 임의 UUID와 저장 시각(밀리초). 세 항목만 Android `SharedPreferences`의 `analysis_history`에 저장합니다.
- 이력은 사용자가 개별 삭제하거나 앱 데이터를 지울 때 삭제됩니다. 자동 만료 기간은 없습니다. Android 자동 백업은 꺼 두었습니다.

## 저장하지 않는 항목

- 카메라·갤러리 **원본 이미지**, 이미지 바이트·썸네일·파일 경로, 이미지 크기, 위치 메타데이터, OCR 좌표, 처리 시간은 이력에 저장하지 않습니다.
- 앱 서버 전송 기능은 없습니다. 한국어 ML Kit 글자 인식은 기기에서 실행합니다.
- 사진 선택기와 카메라가 작업 중 앱 캐시에 임시 복사본을 만들 수 있습니다. 앱은 분석 완료 또는 화면 이탈 시 해당 앱 소유 캐시 파일을 삭제하고, 다음 시작 시 남은 이미지 캐시도 정리합니다. 사용자의 갤러리 원본은 삭제하지 않습니다. 앱이 강제 종료되면 다음 시작 전까지 임시 캐시가 남을 수 있습니다.
- 제출용 `assets/samples/`의 시연 이미지는 개발 프로젝트에 포함된 고정 샘플이며 사용자가 선택한 원본 사진이 아닙니다.

## 공유

사용자가 **공유**를 누를 때만 Android 시스템 공유 시트에 결과 텍스트를 전달합니다. 선택한 외부 앱의 보관·전송 방식은 해당 앱에 따릅니다. 이미지는 공유하지 않습니다.
