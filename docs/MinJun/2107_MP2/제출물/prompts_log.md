# AI 프롬프트와 반영 기록 · MP2

- 사용자 요청: MP1 앱에 ML Kit/TFLite 분석 결과 표시, 인식 불가 안내, 비행기 모드 확인, 처리 시간 README 기록.
- Codex 제안·채택: 기존 Kotlin ML Kit 한국어 Text Recognition에 `analyzeOcr` 전용 진입점을 추가하고 Flutter 결과 화면에 줄 목록·측정 시간을 표시. 모델 다운로드가 필요한 기존 개체 추출 경로는 이번 MP에서 호출하지 않음.
- 실제 검증 후 수정: 흰색 이미지에서 0줄은 오류가 아닌 `no_text` 안내로 처리. 에뮬레이터의 일반/비행기 모드/빈 이미지 스크린샷과 989/1077/70ms 단일 측정값을 README에 기록.
- AI 응답을 그대로 제출하지 않고 앱 빌드와 에뮬레이터 실행 결과를 기준으로 문구를 정리함.
