# MinJun 인수인계

## 현재 상태

사진 인식 앱 2107 MP1·MP2·MP3를 단계별로 `2107_MP1/`, `2107_MP2/`, `2107_MP3/`에 보관했다. 각 폴더에 `제출물/`, ZIP, `검증_기록.md`가 있다. 최신 실행 소스는 저장소의 `screen_guide_test/`이며 MP3까지 반영돼 있다.

## 확인 자료

- `실제_구현_구조.md`: 단계별 실제 코드 경로와 파일 역할.
- 각 단계 `제출물/README.md`와 `screenshots/`: 실행 방법과 에뮬레이터 증거.
- MP3 `제출물/PRIVACY.md`: 저장·비저장 범위.

실기기 카메라 촬영 품질과 사이트 업로드 접수 상태는 아직 확인하지 않았다.
