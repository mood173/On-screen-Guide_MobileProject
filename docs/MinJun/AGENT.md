# MinJun 작업 지침

공통 지침 `../AGENT.md`를 먼저 읽는다. 사진 인식 앱 2107 미니프로젝트의 MP1·MP2·MP3 결과는 이 폴더의 `2107_MP1/`, `2107_MP2/`, `2107_MP3/`에 단계별로 보관한다.

- 각 단계의 `제출물/`과 ZIP은 같은 단계에서 검증한 실행 소스와 증거 화면만 담는다.
- 최신 소스는 저장소 `screen_guide_test/`이고 단계별 `제출물/app/`은 버전 스냅샷이다. 최신 소스를 수정할 때 과거 단계 스냅샷을 덮어쓰지 않는다.
- `실제_구현_구조.md`에는 코드 경로와 실제 에뮬레이터 확인 결과를 유지한다. 새로운 검증 없이 기능 통과를 추가하지 않는다.
- 팀원 `cijghk`, `wlgud`의 개인 폴더는 각 팀원의 작업 공간으로 유지한다.
