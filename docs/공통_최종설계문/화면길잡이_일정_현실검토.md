> 이 문서가 답하는 것: **협업 규격의 날짜가 세 명의 실제 시간으로 가능한가.** 가능하지 않은 곳은 어떻게 옮기거나 줄이는가.

## 3. 조정안

### 3-1. 일 옮기기

화면을 그리는 일이 아닌 것은 형주가 아니어도 할 수 있다. 계산만 하는 함수와 시험을 강민준에게 옮긴다. 폴더 소유는 그대로 두고, 그 파일만 강민준이 만들어 PR로 넣는다.

| 옮기는 일 | 시간 | 누구에게 | 이유 |
|---|---|---|---|
| 단계 맞추기 함수 + 시험 3경우 | 2 | 강민준 | 입력과 출력만 있는 계산이다. 규칙을 정한 사람이 만든다 |
| 공유 텍스트 만들기 함수 + "인식 글자·가린 값 없음" 시험 | 2 | 강민준 | 개인정보 경계를 확인하는 시험이다 |
| 좌표 변환 함수 + 시험 | 1 | 강민준 | 채널 응답의 상자 형식을 아는 사람 |
| 복구 표 (오류 코드 → 문구·버튼) 초안 | 2 | 강민준 | 오류 코드를 내는 쪽 |
| Flutter 쪽 분석기 파일(채널 호출, 가짜 분석기) 관리 | 2 | 강민준 | 분석 규칙을 고치면 어차피 같이 고쳐야 한다 |
| "확인 화면 없이 공유되는 길 0개" 시험 | 2 | 강민준 | 위와 같은 경계 시험 |
| **옮기는 합계** | **11** | | |

### 3-2. 일 줄이기

| 줄이는 일 | 줄어드는 시간 | 어떻게 |
|---|---|---|
| 버튼 등록부 | 형주 −4 | 등록부(표)를 새로 만들지 않는다. 지금의 `switch`를 **빠짐없이 쓰는 형태**로 두면, 버튼 ID를 추가하고 처리하지 않았을 때 컴파일러가 알려 준다. "모든 ID에 핸들러" 시험이 하던 일을 컴파일러가 한다. `switch`의 각 갈래는 기능별 핸들러 함수를 부르기만 한다 |
| 설정 화면 | 형주 −2 | 권한 상태와 맵 revision 두 줄만. 동기화 동의는 뺀다 |
| 기능 맵 저장 | 정혁 −2 | 로컬 DB 대신 **앱에 든 JSON 파일**을 읽는다. 대상이 앱 1~2개·기능 3개라 DB가 필요 없다. 기록만 DB를 쓴다 |
| CI | 정혁 −3 | 12/2까지 남는 시간이 있을 때만 |
| Firebase 맵 갱신 | 정혁 −8 | **지금 뺀다.** 12/2에 판단하지 않는다. 가짜 구현(항상 최신)을 그대로 둔다 |
| 분석 중 체크 3개 연출 | — | 지금 골격 그대로 |
