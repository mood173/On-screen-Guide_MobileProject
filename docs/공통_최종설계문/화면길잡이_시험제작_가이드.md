# 화면길잡이 시험 제작 가이드 (Android · Kotlin · Jetpack Compose)

> **목표:** 프로젝트에서 가장 어렵고 위험한 두 가지를 실제 폰에서 먼저 돌려 본다.
> 1. **시험 1:** 갤러리 스크린샷 → 기기 안 한국어 글자 인식(ML Kit) → 글자 위치에 상자 표시
> 2. **시험 2:** 접근성 서비스로 다른 앱의 버튼 글자 찾기 → 그 위치에 테두리 안내창 띄우기
>
> 여기서 짜는 Kotlin 코드(글자 인식·접근성·안내창)는 나중에 **KMP로 가든 Flutter + Kotlin으로 가든 그대로 재사용**된다.
> 화면은 일단 Jetpack Compose로 간단히 붙인다.

## 3. 시험 1: 스크린샷 → 한국어 글자 인식 → 상자 표시

### 3-1. `OcrHelper.kt` 만들기

`app/src/main/java/com/example/screenguide/` 폴더에서 우클릭 → New → Kotlin Class/File → `OcrHelper` (File)

```kotlin
package com.example.screenguide

import android.content.Context
import android.graphics.Bitmap
import android.graphics.BitmapFactory
import android.graphics.Canvas
import android.graphics.Color
import android.graphics.Paint
import android.net.Uri
import com.google.mlkit.vision.common.InputImage
import com.google.mlkit.vision.text.TextRecognition
import com.google.mlkit.vision.text.korean.KoreanTextRecognizerOptions

object OcrHelper {

    // 한국어 인식기. 앱 전체에서 하나만 만들어 재사용한다.
    private val recognizer = TextRecognition.getClient(
        KoreanTextRecognizerOptions.Builder().build()
    )

    /**
     * 이미지에서 글자를 찾고, 글자 줄마다 빨간 상자를 그린 그림과 글자 목록을 돌려준다.
     * 원본 이미지는 기기 밖으로 보내지 않는다.
     */
    fun run(
        context: Context,
        uri: Uri,
        onDone: (Bitmap, List<String>) -> Unit,
        onError: (String) -> Unit,
    ) {
        val bitmap = context.contentResolver.openInputStream(uri)?.use {
            BitmapFactory.decodeStream(it)
        }
        if (bitmap == null) {
            onError("이미지를 읽지 못했어요")
            return
        }

        // 같은 비트맵으로 인식해야 상자 좌표가 그림과 정확히 맞는다.
        val image = InputImage.fromBitmap(bitmap, 0)
        val started = System.currentTimeMillis()

        recognizer.process(image)
            .addOnSuccessListener { result ->
                val out = bitmap.copy(Bitmap.Config.ARGB_8888, true)
                val canvas = Canvas(out)
                val paint = Paint().apply {
                    style = Paint.Style.STROKE
                    strokeWidth = 6f
                    color = Color.RED
                }
                val lines = mutableListOf<String>()
                for (block in result.textBlocks) {
                    for (line in block.lines) {
                        line.boundingBox?.let { canvas.drawRect(it, paint) }
                        lines += line.text
                    }
                }
                val ms = System.currentTimeMillis() - started
                onDone(out, listOf("인식 시간: ${ms}ms · 줄 ${lines.size}개") + lines)
            }
            .addOnFailureListener { e ->
                onError("글자 인식 실패: ${e.message}")
            }
    }
}
```

> 휴대폰 스크린샷은 바로 맞는다. 카메라로 찍은 사진은 회전 정보(EXIF) 때문에 상자가 어긋날 수 있다. 시험 단계에서는 스크린샷으로 확인한다.

### 3-2. `MainActivity.kt` 바꾸기

템플릿의 `MainActivity.kt` 내용을 전부 아래로 바꾼다. 시험 2용 버튼도 미리 들어 있다.

```kotlin
package com.example.screenguide

import android.content.Intent
import android.graphics.Bitmap
import android.os.Bundle
import android.provider.Settings
import android.widget.Toast
import androidx.activity.ComponentActivity
import androidx.activity.compose.rememberLauncherForActivityResult
import androidx.activity.compose.setContent
import androidx.activity.result.PickVisualMediaRequest
import androidx.activity.result.contract.ActivityResultContracts
import androidx.compose.foundation.Image

import androidx.compose.ui.platform.LocalContext
import androidx.compose.ui.unit.dp

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            MaterialTheme {
                Surface(modifier = Modifier.fillMaxSize()) {
                    HomeScreen()
                }
            }
        }
    }
}

@Composable
fun HomeScreen() {
    val context = LocalContext.current
    var picture by remember { mutableStateOf<Bitmap?>(null) }
    var lines by remember { mutableStateOf(listOf<String>()) }
    var target by remember { mutableStateOf("") }

    // 시스템 사진 선택기 (사진 전체 접근 권한이 필요 없음)
    val picker = rememberLauncherForActivityResult(
        ActivityResultContracts.PickVisualMedia()
    ) { uri ->
        if (uri != null) {
            OcrHelper.run(
                context, uri,
                onDone = { bmp, found -> picture = bmp; lines = found },
                onError = { msg -> Toast.makeText(context, msg, Toast.LENGTH_SHORT).show() },
            )
        }
    }

    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp)
            .verticalScroll(rememberScrollState()),
        verticalArrangement = Arrangement.spacedBy(12.dp),
    ) {
        Text("화면길잡이 시험판", style = MaterialTheme.typography.headlineSmall)

        // ── 시험 1 ──
        Button(onClick = {
            picker.launch(PickVisualMediaRequest(ActivityResultContracts.PickVisualMedia.ImageOnly))
        }) { Text("갤러리에서 스크린샷 고르기") }

        picture?.let {
            Image(
                bitmap = it.asImageBitmap(),
                contentDescription = "글자 인식 결과",
                modifier = Modifier.fillMaxWidth(),
            )
        }
        lines.take(30).forEach { Text("• $it") }

        HorizontalDivider()

        // ── 시험 2 ──
        Text("다른 앱 위 안내 (접근성 서비스를 먼저 켜야 함)")
        Button(onClick = {
            context.startActivity(Intent(Settings.ACTION_ACCESSIBILITY_SETTINGS))
        }) { Text("접근성 설정 열기") }

        OutlinedTextField(
            value = target,
            onValueChange = { target = it },
            label = { Text("찾을 버튼 글자 (예: 디스플레이)") },
            modifier = Modifier.fillMaxWidth(),
        )
        Button(onClick = {
            val service = GuideService.instance
            if (service == null) {
                Toast.makeText(context, "접근성 서비스가 꺼져 있어요", Toast.LENGTH_SHORT).show()
            } else {
                service.setTarget(target)
                Toast.makeText(context, "이제 다른 앱을 열어 보세요", Toast.LENGTH_SHORT).show()
            }
        }) { Text("안내 시작") }

        Button(onClick = { GuideService.instance?.setTarget("") }) { Text("안내 끄기") }
    }
}
```

> `GuideService`는 시험 2에서 만든다. 시험 1만 먼저 돌려 보려면 시험 2 부분 버튼 세 개와 `GuideService` 줄을 잠시 주석 처리한다.

## 4. 시험 2: 접근성 서비스 + 다른 앱 위 안내창

### 4-1. `GuideService.kt` 만들기

```kotlin
package com.example.screenguide

import android.accessibilityservice.AccessibilityService
import android.content.Context
import android.content.Intent
import android.graphics.Canvas
import android.graphics.Color
import android.graphics.Paint
import android.graphics.PixelFormat
import android.graphics.Rect
import android.view.Gravity
import android.view.View
import android.view.WindowManager
import android.view.accessibility.AccessibilityEvent

class GuideService : AccessibilityService() {

    companion object {
        // 같은 앱 안의 화면(MainActivity)에서 이 서비스를 부르기 위한 간단한 연결
        var instance: GuideService? = null
            private set
    }

    private var target: String? = null
    private var overlay: BoxView? = null
    private val windowManager by lazy { getSystemService(Context.WINDOW_SERVICE) as WindowManager }

    override fun onServiceConnected() {
        instance = this
    }

    override fun onUnbind(intent: Intent?): Boolean {
        removeOverlay()
        instance = null
        return super.onUnbind(intent)
    }

    override fun onInterrupt() {}

    /** 찾을 글자를 정한다. 빈 글자면 안내를 끈다. */
    fun setTarget(text: String) {
        target = text.trim().ifEmpty { null }
        if (target == null) removeOverlay()
    }

    override fun onAccessibilityEvent(event: AccessibilityEvent?) {
        val wanted = target ?: return
        val root = rootInActiveWindow ?: return

        // 우리 앱 화면 위에는 표시하지 않는다.
        if (root.packageName == packageName) {
            overlay?.update(null)
            return
        }

        // 화면의 버튼·글자 중에서 찾는다 (자동으로 누르지 않는다 → 누르는 건 사용자)
        val node = root.findAccessibilityNodeInfosByText(wanted).firstOrNull()
        if (node == null) {
            overlay?.update(null)
            return
        }
        val bounds = Rect()
        node.getBoundsInScreen(bounds)
        showBox(bounds)
    }

    private fun showBox(bounds: Rect) {
        val view = overlay ?: BoxView(this).also { v ->
            val params = WindowManager.LayoutParams(
                WindowManager.LayoutParams.MATCH_PARENT,
                WindowManager.LayoutParams.MATCH_PARENT,
                // 접근성 서비스 전용 창 → "다른 앱 위에 표시" 권한이 따로 필요 없음
                WindowManager.LayoutParams.TYPE_ACCESSIBILITY_OVERLAY,
                WindowManager.LayoutParams.FLAG_NOT_FOCUSABLE or
                    WindowManager.LayoutParams.FLAG_NOT_TOUCHABLE or      // 터치는 아래 앱으로 통과
                    WindowManager.LayoutParams.FLAG_LAYOUT_IN_SCREEN or
                    WindowManager.LayoutParams.FLAG_LAYOUT_NO_LIMITS,
                PixelFormat.TRANSLUCENT,
            )
            params.gravity = Gravity.TOP or Gravity.START
            windowManager.addView(v, params)
            overlay = v
        }
        view.update(bounds)
    }

    private fun removeOverlay() {
        overlay?.let { windowManager.removeView(it) }
        overlay = null
    }
}

/** 화면 전체를 덮는 투명한 창에 목표 위치만 테두리로 그린다. */
class BoxView(context: Context) : View(context) {
    private var box: Rect? = null
    private val location = IntArray(2)
    private val stroke = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE
        strokeWidth = 10f
        color = Color.parseColor("#FF6D00")
    }
    private val label = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        color = Color.parseColor("#FF6D00")
        textSize = 48f
        isFakeBoldText = true
    }

    fun update(bounds: Rect?) {
        box = bounds
        invalidate()
    }

    override fun onDraw(canvas: Canvas) {
        val r = box ?: return
        // 창이 실제로 놓인 위치만큼 보정 (상태바 등으로 좌표가 밀리는 것 방지)
        getLocationOnScreen(location)
        val left = (r.left - location[0]).toFloat()
        val top = (r.top - location[1]).toFloat()
        val right = (r.right - location[0]).toFloat()
        val bottom = (r.bottom - location[1]).toFloat()
        canvas.drawRect(left - 8, top - 8, right + 8, bottom + 8, stroke)
        canvas.drawText("여기를 누르세요", left, (top - 24).coerceAtLeast(48f), label)
    }
}
```

### 4-2. 접근성 서비스 설정 파일

`app/src/main/res/` 우클릭 → New → Android Resource Directory → Resource type: **xml**
그 안에 `guide_service_config.xml`을 만든다.

```xml
<?xml version="1.0" encoding="utf-8"?>
<accessibility-service xmlns:android="http://schemas.android.com/apk/res/android"
    android:description="@string/guide_service_desc"
    android:accessibilityEventTypes="typeWindowStateChanged|typeWindowContentChanged"
    android:accessibilityFeedbackType="feedbackGeneric"
    android:accessibilityFlags="flagDefault|flagReportViewIds"
    android:canRetrieveWindowContent="true"
    android:notificationTimeout="200" />
```

`app/src/main/res/values/strings.xml`에 두 줄을 추가한다.

```xml
<string name="guide_service_label">화면길잡이 안내</string>
<string name="guide_service_desc">사용자가 요청한 버튼의 위치를 찾아 화면에 테두리로 알려 줍니다. 버튼을 대신 누르지 않으며, 화면 내용을 기기 밖으로 보내지 않습니다.</string>
```

### 4-3. `AndroidManifest.xml`에 서비스 등록

`<application ...>` 안, `<activity ...>` 아래에 추가한다.

```xml
<service
    android:name=".GuideService"
    android:label="@string/guide_service_label"
    android:permission="android.permission.BIND_ACCESSIBILITY_SERVICE"
    android:exported="true">
    <intent-filter>
        <action android:name="android.accessibilityservice.AccessibilityService" />
    </intent-filter>
    <meta-data
        android:name="android.accessibilityservice"
        android:resource="@xml/guide_service_config" />
</service>
```

### 4-4. 확인

1. ▶ 실행 → 앱에서 **접근성 설정 열기**
2. 설정 → 접근성 → **설치된 앱(설치된 서비스)** → **화면길잡이 안내** → 켜기
   - 켜기가 회색으로 막혀 있으면: 설정 → 애플리케이션 → ScreenGuideTest → 우측 상단 ⋮ → **제한된 설정 허용** 후 다시 켠다 (Android 13 이상, APK 직접 설치 시)
3. 앱으로 돌아와 찾을 글자에 `디스플레이` 입력 → **안내 시작**
4. 홈 → **설정 앱** 열기 → "디스플레이" 메뉴에 주황 테두리와 "여기를 누르세요"가 뜨면 성공
5. 테두리가 있어도 아래 메뉴가 **정상적으로 눌리는지** 확인한다 (터치 통과)
6. 앱에서 **안내 끄기** → 테두리가 사라지는지 확인한다

## 5. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| `Unresolved reference: KoreanTextRecognizerOptions` | 의존성 동기화 안 됨 | build.gradle.kts 확인 → Sync Now |
| 글자 인식 결과가 비어 있음 | 사진이 너무 작거나 흐림 | 휴대폰 스크린샷으로 시험 |
| "접근성 서비스가 꺼져 있어요" | 서비스 미활성 | 4-4의 2번 단계 |
| 접근성 켜기 버튼이 회색 | 제한된 설정 (Android 13+) | 앱 정보 ⋮ → 제한된 설정 허용 |
| 테두리 위치가 조금 어긋남 | 기기마다 상태바·노치 높이 차이 | `BoxView`의 위치 보정 확인, 회전 상태 확인 |
| 은행·결제 앱에서 안 뜸 | 보안 화면이 접근성·안내창을 막음 | 정상 동작. 시연은 설정·배달·메신저 앱으로 |
| 버튼을 못 찾음 | 그 버튼이 글자 대신 아이콘이거나 설명(contentDescription)이 없음 | 다른 글자로 시험. 아이콘 버튼은 나중에 글자 인식 결과와 함께 처리 |

- **KMP로 가는 경우:** Android Studio에서 Kotlin Multiplatform 새 프로젝트를 만들고,
  - `OcrHelper` · `GuideService` · `BoxView` → `androidMain`으로 옮긴다
  - 화면(`HomeScreen`) → `composeApp`으로 옮긴다
  - 안내 흐름·단계 데이터 → `commonMain`에 둔다
