# 최종 · 입력 연결 (결과 → 화면, 카메라 흐름, 권한 안내 DENY·카메라 접근 CP)

2026-11-14 · 지형주 · 브랜치 `feat/input-connect` (협업규격_최종 4.2 4번)
작업 기록: `ai_log/2026-11-14_입력연결.md` · 설계: 협업규격 3.4(결과 → 화면 표·호출 시점)·3.6, 시스템설계 3-0·3-3·3-9·4-1

## 하는 일

갤러리·카메라 포트(`GalleryInput`·`CameraInput`·`InputCleanup`)를 흐름에 연결하고, 포트가 돌려준 결과를
협업규격 3.4 표대로 화면으로 바꾼다. 카메라 흐름(CP·CR·CA·RC)과 권한 안내(DENY)를 화면까지 만든다.

```
갤러리: H → G → GS → GR → GA → RG → D1… → DONE
카메라: H → CP 카메라 접근 → (기기 기본 카메라) → CR → CA → RC → D1… → DONE
권한 거부 → DENY          읽기 실패·분석 실패 → E
```

## 쓰는 법

| 항목 | 내용 |
|---|---|
| 결과 → 화면 | `GuideFlow._onPickFailed(status, 입력 방식)` — 갤러리·카메라 공통 |
| 카메라 버튼 | `captureCamera` → `_openCamera`: 홈에서면 CP로, CP·E에서면 바로 촬영(`_takePhoto`) |
| 다시 찍기 | `captureRetake` → `_retake`: 카메라 세션이면 바로 촬영(CP 생략), 갤러리면 목록으로 |
| 같은 장면, 입력 방식만 다름 | `_scene(gallery: GA, camera: CA)` — 분석 중·결과·확인 장면을 세션의 입력 방식으로 고름 |
| 설정 열기 | `settingsOpenPermission` → `InputCleanup.openAppSettings()`, 화면은 DENY에 머묾 |
| 세션 값 (읽기 전용) | `deniedInput`(권한이 거부된 입력 방식), `capturing`(사진 가져오는 중) |
| 화면 | CP `features/capture/ui/camera_permission_screen.dart`, DENY `features/settings/ui/deny_screen.dart`. CR·CA·RC는 GR·GA·RG 위젯 재사용(시스템설계 3-0 "위젯 하나, 입력 방식만 인자") |

## 결과

| 포트 결과 | 화면 | 세션 |
|---|---|---|
| `ok` (경로 있음) | 갤러리 GR / 카메라 CR | `picked` = 새 사진, 앞 사진 복사본 삭제 |
| `cancelled` | 그 자리 유지 | 바뀌지 않음 (카메라 다시 찍기 취소면 앞 사진 그대로) |
| `permissionDenied` | **DENY** (`PERMISSION_DENIED`) | `deniedInput` = 거부된 입력 방식 |
| `readFailed`, `ok`인데 경로 없음 | E (`IMAGE_READ_FAILED`) | — |

DENY 문구·버튼은 `deniedInput`으로 고른다 (기능별_검토_결론, 필수). 배치는 Figma 15:287.

| | 카메라 거부 | 갤러리 거부 |
|---|---|---|
| 큰 글씨 | 카메라 권한이 허용되지 않았어요 | 사진 접근 권한이 허용되지 않았어요 |
| 버튼 | 카메라 권한 확인 · 갤러리에서 선택 | 사진 권한 확인 · 다시 시도 |

두 번째 버튼은 둘 다 `captureGallery`(갤러리 열기 = 사진 권한 다시 확인)다. Figma의 "실시간 권한 확인"은 13장 X5로 뺐다.
CP는 Figma 15:113 그대로, 두 곳만 바꿨다: 버튼 "카메라 허용 · 체험" → "카메라 허용", 카드 "사진은 분석 후 원본을 보관하지 않아요"
→ "찍은 사진은 안내가 끝나면 지워요"(안내 단계마다 같은 사진을 다시 분석하고, 세션이 끝날 때 복사본을 지운다 — 시스템설계 10-1).

## 한계와 남은 것

- 매니페스트에 카메라·사진 권한 선언이 없다(`android/`). 선언 전에는 실제 기기에서 카메라 거부 → DENY가 생기지 않는다.
- 좌표 변환 함수(4.2 4번 마지막)는 담당 확인 중 (문서는 지형주, 일정_현실검토 제안은 강민준).
- 오류 화면 E에서 다른 입력으로 떠날 때 앞 사진 복사본을 바로 지우는 것은 4.2 7번(11/27). 지금은 다음 사진을 받거나 홈으로 갈 때 지운다.
- 사진을 가져오는 중 "모든 버튼 잠금"이 불편하지 않은지는 실기기에서 확인하지 않았다 (큰 사진 복사 시간, 그 사이 뒤로를 눌렀을 때).
- 카메라 거부 뒤 "카메라로 다시 시도" 버튼은 없다(3-9 DENY 버튼은 둘). 설정에서 허용한 뒤 뒤로 → 홈 → 카메라.
- 결과 화면 큰 글씨 "무엇을 하고 싶으세요?"는 Figma "어떤 도움이 필요하세요?"와 다르다 (골격 때부터, 미결).
