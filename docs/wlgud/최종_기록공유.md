## 하는 일

안내가 끝난 뒤 쓰는 화면을 만든다: 지난 안내를 다시 보는 **기록**, 권한·안내 자료를 보는 **설정**,
보내기 전에 개인정보 후보를 알리는 **공유 전 확인(P)**과 사용 방법 글을 보내는 **공유(SHARE)**.
그 바탕으로 버튼 28개가 "누르면 무엇을 하나"를 빠짐없이 적은 **버튼 등록부**를 둔다.

```
완료 DONE → 안내 기록에 저장
         → 공유하기 → P 공유 전 확인 → 확인했어요 → SHARE 공유하기 → 보내기 → (공유 시트) → DONE
홈 하단 탭 → HISTORY 내 안내 기록 (목록 · 펼쳐 보기 · 지우기 · 이 안내 공유하기 → P …)
          → SETTINGS 설정 (카메라·사진 권한 관리 → 기기 설정 · 저장한 안내 기록 · 안내 자료 버전)
뒤로: SHARE → P → 들어온 곳(DONE 또는 그 기록을 펼친 HISTORY) / 펼침 → 목록 → 홈
```

## 쓰는 법

| 항목 | 내용 |
|---|---|
| 버튼 등록부 | `GuideFlow.dispatch` = 관문(`allows`) + `handle`(switch, `default` 없음). 버튼 ID가 늘고 갈래를 안 쓰면 **컴파일 오류**. 아직 없는 기능 6개(동기화·맵 갱신·실시간 안내 4개)는 `GuideFlow.notReady`에 적고 "준비 중" 문구만. `handle`은 시험 전용(`@visibleForTesting`) |
| 기록 | `navHistory` → `historyItems` 읽기, `historyOpen(id)` → `openedEntry`, `historyDelete(id)` → 지우고 다시 읽기(확인창은 화면이 띄움). 기록 단계를 떠나면 비운다 |
| 설정 | `navSettings` → `mapRevision`(`GuidanceRepository.activeRevision`). 권한 상태는 읽지 않는다 — "권한 관리" 줄이 `settingsOpenPermission`으로 기기 설정을 연다 |
| 공유 들어가기 | `sharePrepare`: DONE이면 세션의 기능 + 후보(유형 + 가린 값), 기록이면 **펼친 기록** + 유형 이름만 → `ShareDraft` → P. 공유 단계에 들어갈 때 "확인함"을 지운다 |
| 확인 | `shareConfirm`(P의 "확인했어요")만이 "확인함"을 켠다 → SHARE에서 `shareSend`가 열린다 |
| 보내기 | `shareSend` → `flow.shareText`(= `buildShareText(제목, 단계 문구)`) → `Sharer.shareText` → 결과 세 갈래 → 들어온 곳 |
| 공유 글 | `shared/share_text.dart`의 순수 함수. 받는 것은 기능 제목·단계 문구 글자뿐이라 화면 글자·개인정보가 섞일 길이 없다. 미리보기와 보내기가 같은 함수 |
| 잠금 | 기록·설정 값을 읽는 동안(`loadingRecords`), 공유 시트 동안(`sharing`) 모든 버튼 잠금 — `capturing`과 같은 방식, try/finally |
| 화면 | HISTORY `features/history/ui/history_screen.dart`, SETTINGS `features/settings/ui/settings_screen.dart`, P `features/privacy/ui/privacy_check_screen.dart`, SHARE `features/share/ui/share_screen.dart`, 하단 탭 `shared/cells/app_tab_bar.dart`. P·SHARE는 흐름을 받지 않고 **값(후보 목록 / 보낼 글)과 버튼 동작만** 받는다 |
