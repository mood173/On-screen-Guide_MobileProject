## 3. 하나씩 물어본 것

| 단위 | 물어본 것 | AI의 설명 | 내 판단 |
|---|---|---|---|
| D-1 | 왜 클래스나 포트가 아니라 맨 바깥 함수 하나인가 | 구현이 하나뿐인 순수 계산이라 갈아 끼울 일이 없다(X7). 클래스로 감싸면 쓰지 않는 껍데기만 생긴다. 같은 값을 넣으면 늘 같은 값이 나오니 시험도 값만 비교하면 된다 | |
| D-1 | 왜 `sx`·`sy`를 따로 계산하나 | 화면에 그린 크기의 비율이 원본과 조금이라도 다르면(반올림, `BoxFit.fill`) 하나의 비율로는 한쪽이 어긋난다. 따로 곱하면 어떤 크기에 그려도 같은 자리가 된다 | |
| D-1 | `Rect.zero` 한 줄은 왜 넣나 | 원본 크기가 0이면 0으로 나눠 무한대가 되고, 그 자리에 그리려다 화면이 깨진다. 정상 응답에선 없지만 계약상 `imageSize`가 없으면 0이 된다(`analysis.dart` 296줄) | |
| D-1 | 테두리 여유(`inflate`)는 왜 함수에 안 넣나 | 몇 픽셀 띄울지는 그리는 방식(디자인)이라 화면 부품이 정한다. 좌표 계산과 섞으면 시험이 디자인 값에 묶인다 | |
| D-1 | 문서의 "↔"인데 왜 한 방향만 만드나 | 화면 → 원본으로 거꾸로 바꾸는 곳이 없다(실시간 오버레이는 제외 범위). 쓰지 않는 함수는 만들지 않고, 필요해지면 그때 추가한다 | |
