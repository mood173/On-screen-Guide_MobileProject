# AI 프롬프트와 답변 기록

## 요청 1 · 과제 검토와 제작

**사용자 요청 요지:** 중간보고서와 AI-ANT 진행 폴더를 읽고, 사진 인식 앱 2107번 미니프로젝트의 1단계를 기존 `On-screen-Guide_MobileProject`에서 Codex로 제작할 수 있는지 확인.

**AI 답변·판단:** Codex로 Flutter·Android Kotlin 프로젝트 작업이 가능하다. 1단계의 제출 기준은 카메라·갤러리 이미지 입력, 화면 표시, 권한 거부 시 안내와 README 설명이다. 기존 OCR 시험 기능은 이후 단계용으로 보존한다.

**반영:** 카메라·갤러리 선택, 미리보기·이미지 표시, 권한 거부 안내·설정 이동, 취소·파일 오류 처리를 구현. 기존 분석 화면 코드를 보존.

## 요청 2 · 프로젝트 문서 구조

**사용자 요청 요지:** `docs` 최상단에 공통 `AGENT.md`를 만들고, 팀원이 이번 미니프로젝트 자료를 바로 볼 수 있게 구성.

**추가 설명:** 역할별 폴더가 아니라 `11월_9일 1번미니프로젝트` 폴더에 AI 프롬프트·답변 결과와 제출용 폴더 묶음을 둔다.

**반영:** 공통 작업 지침과 날짜별 과제 폴더를 만들고, 제출 기준의 네 최상위 항목을 날짜 폴더 아래 `제출물/`에 배치.
