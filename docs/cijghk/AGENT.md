# cijghk 개인 작업 지침

**작업을 시작하기 전에 `작업_맥락.md`를 먼저 읽는다.** 담당 범위, 기준 문서, 마감, 규칙, 현재 상태가 거기 있다. 작업 중 바뀐 사실은 그 문서에 반영한다. 같은 폴더에 `로컬_환경.md`(내 PC 전용, git에 올리지 않음)가 있으면 함께 읽는다.

공통 지침 `../AGENT.md`와 팀 기준 문서 `../공통_최종설계문/화면길잡이_협업규격_최종.md`를 따른다. 역할은 확정됐다: 최정혁은 **데이터·입출력**(협업규격_최종 4.3 — 사진 가져오기, 기능 맵 스키마·저장소, 기록 DB, 공유, 기능 맵 갱신, CI). 다른 사람의 폴더는 고치지 않고 요청한다.

이 폴더에 두는 것:
- `데이터_입출력_설계.md`: 내 담당의 구현 설계
- `ai_log/<날짜>_<기능>.md`: 기능별 AI 작업 기록 (시스템역할설계 7장 양식)
- `완성본/최종_<기능>.md`: 기능이 끝났을 때의 최종 설명 (PR 전에). **최종 문서는 항상 `완성본/` 폴더에 둔다**
- `HANDOFF.md`: 변경 파일, 실제 검증 결과, 남은 확인

`../11월_9일 1번미니프로젝트/`는 미니프로젝트 1단계 제출 기록이다. 팀 앱(`screen_guide/`) 작업 기록은 이 폴더에 둔다.
